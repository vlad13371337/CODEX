# Popkorm Club

Современный лендинг на React о коллекциях авторского попкорма для событий. Проект собран на базе Vite и включает интерактивные блоки с описанием вкусов, отзывами, FAQ и формой заявки.

## Скрипты

- `npm install` — установка зависимостей.
- `npm run dev` — запуск дев-сервера Vite.
- `npm run build` — сборка production-версии.
- `npm run preview` — предпросмотр собранного приложения.
